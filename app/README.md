# AI Business Intelligence Platform

A FastAPI-based Business Intelligence Backend Project.

### Authentication
- User Registration
- User Login
- JWT Authentication

### Company Management
- Create Company
- Read Company
- Update Company
- Delete Company

### Search & Filtering
- Search Companies
- Filter by Industry
- Filter by Country

### Data Analysis
- Company Statistics
- Industry Analytics
- Country Analytics
- Dashboard Analytics

### Reports
- Top Industries Report
- Top Countries Report
- Business Report

### Export
- Export Companies to CSV
- Export Companies to Excel

### Logging
- Application Logging
- Request Logging
- Error Logging

## ⚙️ Installation

Clone Repository

```bash
git clone <repository-url>
cd AI-Business-Intelligence
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Environment

```bash
venv\Scripts\activate
```

Install Requirements

```bash
pip install -r requirements.txt
```

Run Server

```bash
python -m uvicorn app.main:app --reload
```

Swagger Docs

```
http://127.0.0.1:8000/docs
```
